# Fontes fiéis das provas de lançamento oblíquo de 2026

Este diretório contém as fontes Moodle específicas das três provas impressas:
Mecânica, Informática e Automação.

Cada turma possui 10 arquivos `Q01.Rnw`--`Q10.Rnw`. Cada arquivo seleciona
uma das 10 versões que foram efetivamente impressas e usa o recorte visual
correspondente em `assets/`.

Os PNGs são derivados exclusivamente dos PDFs limpos de geração das provas,
anteriores à aplicação. Não há dados de estudantes neste diretório.

A finalidade desta coleção é **fidelidade à avaliação aplicada**, não
reutilização editorial: enunciado, figura, parâmetros e alternativas devem
coincidir com a versão impressa escolhida. Alterações futuras no banco
canônico de lançamento oblíquo não devem modificar retroativamente estas
fontes.

A geração Moodle é feita por
`tools/generate_lancamento_obliquo_provas_2026.R`.
