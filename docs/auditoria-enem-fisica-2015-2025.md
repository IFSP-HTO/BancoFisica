# Auditoria ENEM Física 2015–2025

> Base analisada: `master` no commit `9141140ffb72b17a467af9926b7d2a67e573a397`.

## Método

Foram triadas individualmente as 495 questões de Ciências da Natureza das 11 provas regulares de 2015 a 2025. A classificação segue o conceito físico dominante. Uma questão só conta como **presente** quando a questão/contexto ENEM foi efetivamente incorporado ou adaptado; ter uma questão genérica sobre o mesmo conceito não conta como cobertura.

Questões oficialmente anuladas permanecem registradas no inventário histórico, mas não entram na fila de incorporação.

Legenda: ✅ presente; ⬜ ausente de Física; 🟨 híbrida para revisão; 🚫 anulada; 🖼️ questão com figura/gráfico/circuito/esquema relevante no original.

## Regra de manutenção

Todo PR que incorporar uma questão deste inventário deve referenciar a issue da auditoria e atualizar este documento, retirando o item da fila e registrando o caminho do `.Rnw`. Questões oficialmente anuladas permanecem apenas como registro histórico. Aplicações PPL, reaplicações e provas extraordinárias ficam fora deste universo e devem ter auditoria separada.
